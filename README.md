# Mission Control 1.0 — GitHub upload package

Upload the CONTENTS of this folder to the root of `frostscienceedu/Mission-Control`.

Required files:
- index.html
- manifest.json
- service-worker.js
- icons/icon.svg
- images/ (reserved for final locally stored mission photos)

Then in GitHub:
Settings → Pages → Deploy from a branch → main → /(root) → Save.

Important: this package preserves the approved Mission Control prototype and adds the PWA installation/offline shell. The final production pass should replace externally hosted mission photos with approved local files so all photography works completely offline.
